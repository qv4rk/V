# FeistTech Reading Room extension v0.3
Responsive Kiwi/mobile + desktop test build.

Sources: open tab, pasted text, one upload button. PDF upload uses PDF.js. Open-tab adapters include generic webpages, Google Docs direct authenticated text export with fallbacks, and YouTube transcript opening/extraction. Text is normalized into paragraph units and three-paragraph sections.

Voice browser order: Multilingual, English, Chinese, African, Spanish, then remaining language groups alphabetically. Rows show voice name and country where the browser exposes those details.

Next audio milestone: port the working Edge-TTS Blob synthesis from the full Reading Room so section MP3 and whole-source MP3 downloads can be produced.
