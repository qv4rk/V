Termux APK builds

On-device Android APK build

A known-good Termux pipeline that compiles, packages, signs, and aligns a small test APK on an ARM64 Android phone. It was checked end to end on 26 September 2026: the APK installed and launched on the device. The published scripts do not include a keystore or a password. If a keystore is missing, build-apk.sh creates one at ~/.feisttech-test.keystore and prompts for a password; keep that file and password on the phone.

How to run it

Install the Java and Android SDK tools first. The full environment notes are in the guide linked below. Then, in Termux:

curl -L -o android-on-device-build.zip https://feisttech.com/tools/downloads/android-on-device-build.zip
unzip android-on-device-build.zip
cd android-on-device-build
chmod +x verify-environment.sh build-apk.sh
./verify-environment.sh
./build-apk.sh

The finished APK is written to build/FeistTech-APK-Test.apk. You can also clone the source repository: qv4rk/ftechbuilds.

Chrome extensions

Batch Image Pipeline v3.0

A Chrome and Kiwi extension, and a standalone studio, for generating and saving batches of images. It keeps a local image vault, trims watermarks, rejects near-duplicate frames, and can write finished files to a folder you choose. API keys, if you use them, are entered in the extension and are not stored in this package.

How to load it

curl -L -o batch_image_extension_v3.zip https://feisttech.com/tools/downloads/batch_image_extension_v3.zip
unzip batch_image_extension_v3.zip -d batch_image_extension_v3

In Chrome or Edge: open chrome://extensions, turn on Developer mode, choose Load unpacked, and select the unzipped folder. In Kiwi on Android: menu → Extensions → Developer mode → Load unpacked, then pick the same folder.

Feist Doc Audio Capture

A Manifest V3 extension that records the audio playing in a browser tab — for example, Google Docs “Listen to this document” — and saves it as a .webm file. It was written for Kiwi on Android, where the toolbar popup is unreliable, so the controls live in a Recorder tab instead.

How to load it

The public source is in this repository under extension/. Two packaging files, recorder.html and offscreen.html, are kept off the published site, so this folder alone is not a complete Load unpacked package. Use a local copy that still has those files, or add them back before loading the extension.
