# Planet and moon textures

These image files are **not** copied from an official GitHub data repository. They were already in the Atlas preview / Scale Orrery trees. There is no commit SHA to record for a first-party GitHub source.

- Sun and planet maps (`2k_*.jpg`): [Solar System Scope](https://www.solarsystemscope.com/textures/) texture pack, **CC BY 4.0**. Credit: Solar System Scope.
- Earth (`earth.jpg`): NASA Blue Marble (public domain / NASA credit as in the Atlas preview CREDITS).
- Moon (`moon.jpg`): NASA LROC, via the globe.gl examples path credited in the Atlas preview CREDITS.

Unofficial GitHub mirrors (for example [rajpatel5/Solar-System](https://github.com/rajpatel5/Solar-System) and [elymas/solar-simulator](https://github.com/elymas/solar-simulator)) have circulated similar files. Those mirrors are **not** vendored here, so as not to imply they are the official source or to attach a SHA that may not match these exact bytes.

Do not relicense the Solar System Scope maps; keep the CC BY 4.0 attribution when they are shown.
