# The 1858 Land Code: Bureaucracy as Weapon

The Ottoman Empire issued a land code requiring formal registration. Sounds reasonable. Except the fellahin—Palestinian peasants who'd worked the same land for generations—couldn't navigate the bureaucratic maze. Registration required Ottoman Turkish literacy, travel to distant offices, fees they couldn't afford.

So they borrowed. Debt became coercion. Coercion became transfer. Within decades, land that had been held communally for centuries was registered to urban elites and European creditors who'd never touched a plow.

This is necronomy in its purest form: create an administrative requirement that the target population can't meet, then profit from their failure to comply. No soldiers needed. No conquest declared. Just paperwork, fees, and the inexorable logic of bureaucratic exclusion.

The system worked so well it became a template. Replace "land registration" with "zoning codes," "credit scores," "occupational licensing," or "immigration documentation" and the mechanism remains identical: manufacture complexity, then monetize the inability to navigate it.
